# Cinder Coffee Shop

A small JavaScript practice project that simulates a coffee order using browser prompts and alerts.

## What it does

- Asks for the customer's name and drink order.
- Uses a fixed drink price of $6.
- Adds 10 points to a starting balance of 15 customer points.
- Displays the order summary and a delivery flag set to `false`.

## Concepts practiced

Variables, strings, numbers, booleans, reassignment, string concatenation, `prompt()`, and `alert()`.

## Run it

Open your browser's developer console on a blank page, then paste and run the contents of `cinder-coffee.js`. Answer the two prompts to see the alerts.

This script uses browser APIs; it does not run directly in Node.js. It is a learning exercise, with no checkout, payment processing, or saved customer data.
